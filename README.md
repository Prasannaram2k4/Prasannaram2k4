### 📌 Featured Projects & Deep Dives

#### 📄 [ragnify — AI Document Assistant](https://github.com/Prasannaram2k4/ragnify)
> **Contextual PDF QA Engine powered by RAG, Hugging Face, FAISS, and Streamlit.**
- 💡 **What it does:** An intelligent document interaction platform that ingests complex PDF files, creates dense vector embeddings, and provides fast, highly relevant answers based on context.
- ⚙️ **Key Features:**
  - Automated document chunking and embedding generation using Hugging Face transformers.
  - Sub-second vector similarity search using **FAISS** vector store.
  - Interactive, reactive user interface powered by **Streamlit**.
- 🛠️ **Technologies:** `Python`, `LangChain`, `HuggingFace`, `FAISS`, `Streamlit`

---

#### 🎯 [Insightify — ATS Resume ↔ Job Matcher](https://github.com/Prasannaram2k4/Insightify)
> **Full-stack ATS resume evaluator and interview prep generator.**
- 💡 **What it does:** Compares candidate resumes against job descriptions to calculate TF-IDF match scores, detect missing ATS keywords, and generate custom interview practice questions.
- ⚙️ **Key Features:**
  - Fast text parsing for multi-page `.pdf` and `.txt` files.
  - Mathematical cosine similarity scoring using TF-IDF vectorizers.
  - Tailored interview question recommendations based on candidate skill gaps.
- 🛠️ **Technologies:** `FastAPI`, `React`, `Python`, `JavaScript`, `Scikit-Learn`

---

#### 🤖 [AI-Lead-Discovery-Agent](https://github.com/Prasannaram2k4/AI-Lead-Discovery-Agent)
> **Autonomous lead prospecting & market intelligence agent.**
- 💡 **What it does:** Automates the identification, scraping, and verification of potential business leads across web targets.
- ⚙️ **Key Features:**
  - Asynchronous web scraping and entity extraction pipeline.
  - Structured data format exports ready for CRM integration.
- 🛠️ **Technologies:** `Python`, `AI Agents`, `BeautifulSoup`, `Asyncio`

---

#### 📈 [hyperliquid-sentiment-analysis](https://github.com/Prasannaram2k4/hyperliquid-sentiment-analysis)
> **Data science investigation into DEX trader sentiment vs. market dynamics.**
- 💡 **What it does:** Explores statistical correlations between trader performance metrics on Hyperliquid DEX and the Bitcoin Fear & Greed Index.
- ⚙️ **Key Features:**
  - Automated data collection from exchange APIs and market sentiment feeds.
  - Exploratory Data Analysis (EDA) and visualizations illustrating trader behavior in bullish/bearish trends.
- 🛠️ **Technologies:** `Python`, `Pandas`, `NumPy`, `Matplotlib`, `Hyperliquid API`
